Como funciona

1
O organizador cadastra os nomes e toca em Sortear.
2
O resultado fica escondido: o app gera um código secreto para cada pessoa.
3
O organizador manda cada código pelo WhatsApp. Cada um abre e vê só o próprio amigo secreto.
